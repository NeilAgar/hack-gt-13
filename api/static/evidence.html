What this does and doesn't show

    Method

    • Data: CMS Payroll-Based Journal daily nurse staffing (RN + LPN + CNA hours ÷ census) and CMS Health Standard inspection dates, Georgia only.
    • Day 0 is the inspection's last day. CMS records the survey end date; start dates aren't reliable. We follow Chen & Dillender and anchor on the end date, so the spike before day 0 includes the days inspectors are on site.
    • Residuals: each home's day-of-week pattern, 90-day trend and monthly level are removed first, so weekends and seasons don't read as inspection effects.
    • Per-home scores compare days −14 to −1 with days +28 to +56, are shrunk toward the state average when a home has few or noisy inspections, and always show an uncertainty range.
    • Placebo: the same analysis on random fake dates for each home. A real effect should vanish.

    Limits. PBJ staffing is self-reported by facilities (OIG found about 5% of RN hours unsupported). Most homes have only one or two inspections inside the staffing data, so per-home scores are uncertain. The on-site window assumes a typical 4-day survey; actual survey length varies.
